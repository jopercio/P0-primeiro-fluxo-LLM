# P0 - Primeiro Fluxo com LLM

## Sobre o projeto
Desenvolver uma aplicação funcional em Python que utiliza um modelo de linguagem (LLM), por meio de sua interface programática, para resolver um problema textual pequeno e real.

O projeto representa o primeiro ciclo de desenvolvimento de uma aplicação com Inteligência Artificial, abrangendo desde a identificação e delimitação de uma necessidade até a implementação, integração com um serviço externo, testes e documentação.

### Pergunta Motriz
Como fazer um modelo de linguagem resolver um problema real, do zero, sem depender de um tutorial passo a passo?

## Problema
Uma pessoa que recebe solicitações precisa transformar mensagens informais em registros padronizados, porque atualmente enfrenta dificuldades para organizar e encaminhar as demandas.

## Solução Proposta
### Classificador de solicitações e ocorrências

A aplicação identifica informações relevantes da mensagem e organiza em campos previamente definidos, produzindo uma representação estruturada.

### Fluxo

1. Entrada textual: usuário fornece um texto
2. Processamento: validação e preparação da entrada
3. API do LLM: interpretação e geração de resposta estruturada
4. Processamento da resposta: validação e organização dos campos
5. Resultado útil: exibição das informações ao usuário

### Por que utilizar um LLM?
Pessoas podem descrever uma mesma situação de maneiras muito diferentes. O modelo permite interpretar o contexto e a intenção da mensagem, identificando as informações necessárias para sua classificação e organização.
